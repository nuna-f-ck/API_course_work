# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка

5 часов

## Фактически затраченное время

11 часов


## Реализованный функционал:
1. Интеграция списка постов с API.
2. Страница добавления поста.
3. Страница постов конкретного пользователя.
4. Лайки.
5. Обновление интерфейса без перезагрузки.
